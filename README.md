The website for Q5, a static site built with [Nuxt](https://nuxt.com) and [Nuxt Content](https://content.nuxt.com), deployed on Netlify. Requires Node 24 (see `.nvmrc`).

## Links

**PRODUCTION:** https://q-5.ca/

**BETA:** https://beta.q-5.ca/


## Build Setup

```bash
# install dependencies
$ npm install

# serve with hot reload at localhost:3000
$ npm run dev

# generate the static site into dist/
$ npm run generate

# lint
$ npm run lint
```

Case studies live in `content/work/*.md`, with their images in `public/work/<slug>/`.
